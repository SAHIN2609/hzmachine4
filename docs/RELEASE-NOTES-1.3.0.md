# 1.3.0 — HZ MACHINE PRO

## UI rewrite

- Rebuilt the visual layer around a dark frosted-glass hardware aesthetic.
- Added a premium top preset shell, A/B snapshots, glass navigation, larger amp hero and responsive layouts.
- Added mode-specific accent lighting and more restrained control density.
- Redesigned synth and cabinet pages to match the same product language.
- Preserved the existing WebView/APVTS protocol so automation and state handling remain compatible.

## Presets

- Kept the factory bank guitar-first.
- Limited synth factory content to six signature presets.
- Darkened the preset browser and reduced visual noise.

## Packaging

- Project version: 1.3.0.
- Windows x64 VST3 GitHub Actions build retained.
