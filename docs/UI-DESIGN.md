# HZ MACHINE PRO UI system

The 1.3 UI is an original premium dark-glass interface for SISHHIN HZ MACHINE. It uses a layered hardware presentation rather than copying any commercial interface or branding.

## Visual language

- Deep black / graphite chassis
- Frosted glass panels with restrained blur
- Violet as the Modern/Metal signature
- Cyan for Clean / studio tones
- Amber for Crunch
- Red for Lead
- Gold for Sitar
- Fine 1px separators and low-opacity highlights
- Large central amp/grille hero area
- Compact preset browser with A/B snapshots
- Minimal typography and high information density

## Interaction model

The existing JUCE WebView parameter protocol remains unchanged. Knobs, toggles, mode selectors, cabinet selectors, IR loading, meters, presets and A/B snapshots continue to map to the APVTS parameters.

## Design assets

`Source/ui/assets/` contains original SVG reference assets for the native/WebView design language. They are intentionally generic and contain no third-party brand artwork.
